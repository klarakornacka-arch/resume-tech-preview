# 单屏作品集一级导航舞台设计说明

## 目标

将现有 Bloom 式 500vh 滚动叙事首页改造成固定在首屏的一级导航舞台。首页只承担身份表达、视觉记忆和快速分流，不再承载作品列表、个人介绍、能力说明、设计流程与联系模块的纵向内容流。

目标浏览者是招聘负责人、设计主管与潜在合作方。进入网站后应在十秒内理解设计方向，并能一次点击进入作品、文化 IP、个人介绍或联系页面。

## 页面结构

- 首页高度固定为 `100dvh`，禁止产生页面纵向滚动。
- 视频与 Canvas 动画保持全屏背景，并提供加载失败时的静态封面。
- 左上角保留张振源个人标识；右上角提供作品、关于、联系和简历下载的紧凑导航。
- 左下角保留设计宣言与身份信息，作为首屏默认内容。
- 中央能力面板作为一级交互导航，而非纯展示卡片。
- 移除首页中动画之后的 `FeaturedWorks`、`AboutPreview`、`Advantages`、`DesignProcess` 与 `ContactCTA` 内容流，但不删除这些组件文件，也不影响其他路由。

## 一级入口

首页至少提供以下可直接访问的目标：

1. 产品系统：跳转 `/works?category=Product%20Design`，直接展示产品与工业设计项目。
2. 视觉智能：跳转 `/works?category=AI%20Visual`，直接展示 AI 视觉相关作品。
3. 文化转译：跳转 `/works/longqi-ip-toy`，直接进入龙福潮翁文化 IP 项目。
4. 关于我：跳转 `/about`。
5. 联系：跳转 `/contact`。
6. 下载简历：保持现有 PDF 下载地址。

## 交互状态

### 默认舞台

背景视频自动循环，视觉运动保持缓慢。首屏显示个人标识、宣言和“进入作品导航”控制。页面不依赖滚轮推进动画。

### 导航展开

用户点击主控制或移动指针进入主要交互区域后，三张能力面板在同一视口内展开。面板采用非对称尺寸与清晰边框，内容包括编号、能力名称、简短价值说明和目标提示。

### 悬停反馈

悬停面板仅使用 `transform`、`opacity` 与轻微 `filter`：目标面板向前移动并提高清晰度，其余面板轻微退后。禁止外发光、大幅旋转和连续抖动。每个入口必须具有明确焦点样式与完整键盘操作能力。

### 路由离场

点击入口后，当前面板轻微放大，其他层淡出，然后交给现有 Framer Motion 页面转场进入目标路由。离场动画控制在约 400 毫秒，不延迟实际导航。

## 背景动画策略

- 桌面端不再按滚动位置播放三段视频帧序列，改为按时间自动切换背景片段。
- 第一段素材加载完成后立即解除加载界面，后续视频异步准备。
- 背景交互允许根据鼠标位置产生有限的横向位移、缩放或焦点变化，但不能影响文字点击。
- 移动端直接使用循环视频或静态封面，关闭 Canvas 帧缓存与鼠标视差。
- `prefers-reduced-motion` 下使用静态封面，所有面板直接显示，不执行自动切换与视差。

## 视觉规则

- 延续现有 Nocturnal Bio-Tech Cinematic Editorial 语言。
- 背景使用 `#050506`，主文字使用 `#F5F3F7`，`#CB8DFF` 仅用于选中状态和关键导航提示。
- 面板保持直角或不超过 4px 圆角，使用低透明玻璃和细边框。
- 不增加霓虹发光、渐变光球、规则三列 SaaS 卡片或无意义装饰线。
- 保证 1440、1600 与 1920 像素桌面宽度下所有入口无需滚动即可完整出现。

## 响应式与可访问性

- 桌面端为全屏交互舞台；移动端将能力入口排列为可触摸的紧凑纵向列表，但仍控制在单个视口中。
- 所有目标区域最小触摸尺寸为 44px。
- 视频、Canvas 与装饰层设置为不可拦截指针事件。
- 卡片使用语义链接，并提供可见的键盘焦点状态。
- 资源失败时展示带项目身份和入口的高级静态占位，不出现黑屏。

## 工程边界

- 复用现有 `BloomPortfolioExperience`、React Router 与 Framer Motion。
- 首页数据继续集中在 `bloomExperience.ts`，为能力项增加明确的目标路由；作品页从 `category` 查询参数初始化筛选状态。
- `HomePage` 只渲染单屏体验组件。
- 不删除现有路由、真实作品数据、详情页组件或首页旧组件文件。
- 不新增动画依赖；优先使用现有浏览器视频能力、Canvas 与 Framer Motion。

## 验收标准

- 首页没有纵向滚动条，也不会继续加载动画下方模块。
- 三张能力面板、作品、关于、联系和简历入口全部可用。
- 桌面端背景保持可见、自动变化并响应鼠标；移动端无复杂帧缓存。
- 减少动态效果模式下仍可完整浏览和导航。
- 页面切换不闪黑，视频失败不黑屏。
- TypeScript、测试与 Vite 生产编译全部通过。
